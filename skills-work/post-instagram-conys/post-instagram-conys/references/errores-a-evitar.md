# Errores a evitar (revisión "contrarian")

Pregunta que nos hicimos: *¿qué puede salir mal con esta skill?* Estas son las respuestas, con cómo prevenir cada una.

| Riesgo | Prevención |
|---|---|
| Inventar precios, notas, formatos o stock | Solo datos del input o del segundo cerebro. Lo demás va como `[a completar]` y se lista en "Datos a confirmar" |
| Usar una foto de otra marca (Aesop, Le Labo…) como si fuera de Cony's | Solo fotos propias. Si no hay, se deja el marco vacío o una textura. Las fotos ajenas son referencia de estilo |
| Editar o romper diseños existentes en Canva | Solo diseños NUEVOS, con "(Claude)" en el nombre. Para partir de uno existente, primero se copia |
| Publicar sin revisión | La skill **nunca publica ni programa**. Siempre pide aprobación |
| Sonar a IA genérica ("sumergite en una experiencia única") | Leer `voz.md`. Frases concretas y sensoriales. Cero clichés de marketing |
| Sonar demasiado informal (muletillas de audio) | Las muletillas solo van en MD. En el post, la versión cuidada |
| Español neutro o de España | Voseo rioplatense siempre |
| Mostrar la cara de Patricia | Voz en off, manos y proceso. La cara solo si lo pide |
| Varios CTA que compiten | Uno principal (+ la dirección del atelier como mucho) |
| Links en el caption | Nunca. El CTA lleva a MD o al atelier |
| Datos sensibles (clientes con nombre, montos, conversaciones privadas) | Nunca en un post |
| Copiar frases de otras marcas | Inspirarse en estructuras, no en textos |
| Urgencia falsa ("últimas unidades") | Solo si el input lo confirma |
| Mezclar idiomas | Todo en español |
